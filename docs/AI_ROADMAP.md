# me-budget — แผนใช้ AI เพิ่ม (draft)

ตอนนี้ AI มีจุดเดียวคือสแกนใบเสร็จ (FR-10, `src/infrastructure/ai/GeminiReceiptParser.ts`) ใช้ Gemini + zod schema เป็นสัญญา เอกสารนี้จดแผนต่อยอดไว้ก่อน **ยังไม่เริ่มทำ**

## ข้อจำกัด (ต้องคิดทุกฟีเจอร์)
- **Gemini free tier** ยอมให้ Google เอาข้อมูลไปใช้ (TECH_DESIGN T5) → ส่งข้อมูลออกให้น้อยที่สุด ส่งยอดรวมได้ก็อย่าส่งรายการดิบ
- **โควตานับแล้วแต่ยังไม่บังคับ** (TOR FR-10) → ยิ่งมีจุดเรียก AI มาก ยิ่งต้องบังคับ
- **หัวใจคือจดเร็ว** (FR-1) → ฟีเจอร์ AI ห้ามทำให้ flow หลักช้าลง และต้องมีทางจดมือเสมอเมื่อ AI ล้ม
- **ไม่ผูกบัญชีธนาคาร** (TOR หัวข้อ 3) → นำเข้าจากรูป/ไฟล์ที่เราส่งเองได้ แต่ไม่ต่อ API ธนาคาร

## แผนที่ตกลงแล้ว (เฟส 0-3)

| เฟส | งาน | หมายเหตุ |
|---|---|---|
| 0 | บังคับโควตา AI ต่อบัญชี (นับรวมทุกฟีเจอร์) · เพิ่ม `GEMINI_MODEL` ใน `.env.example` | ต้องทำก่อนเปิดจุดเรียก AI ใหม่ |
| 1 | **สแกนสลิปโอนเงิน** (PromptPay / แอปธนาคาร) → ยอด เวลา ชื่อผู้รับ → ร่างรายการ | ใช้ ScanScreen + โครง parser เดิม สมมติว่าจ่ายผ่าน QR บ่อย |
| 2 | **จดด้วยประโยคเดียว** เช่น "ข้าวมันไก่ 60 หารแฟน" → ร่างรายการ (ยอด หมวด คน วิธีหาร กระเป๋า) | เริ่มจากพิมพ์ แล้วค่อยเพิ่มเสียง (Web Speech API ของ browser ฟรี) |
| 3 | **สรุปรายเดือนเป็นภาษาคน** 3 บรรทัด | ส่งแค่ยอดรวมต่อหมวด ไม่ส่งรายการดิบ · สร้างเดือนละครั้งแล้ว cache · ทำคู่กับ FR-6 |

โครงเดียวกันทุกฟีเจอร์: port ใน `application/ports` → adapter ใน `infrastructure/ai` → zod schema เป็นสัญญา → AI ล้มก็กลับไปจดมือ

### ไม่ต้องใช้ AI (โค้ดธรรมดาดีกว่า เร็วกว่า ฟรี)
- ระบบเสนอปุ่มลัด v1.1 — กฎมีแล้ว (จดซ้ำ 3 ครั้งใน 14 วัน)
- งบแนะนำ FR-5 — ค่าเฉลี่ยย้อนหลัง 3 เดือน
- ราคาของที่ซื้อบ่อย — ชื่อกลางจาก AI มีอยู่แล้วใน `receipt_lines` แค่ group ตามชื่อกลางก็เห็นราคาขึ้น/ลง
- จับรายการซ้ำ (สแกนแล้วจดมือซ้ำ) — เทียบยอด + เวลา
- จับค่าสมาชิกรายเดือน — ยอดเดิม โน้ตเดิม ทุกเดือน
- เดาว่าลืมจด ("ปกติพุธซื้อกาแฟ 55") — ดูจากรูปแบบเดิม
- ข้อความทวงเงิน — template ใน `src/client/debtMessage.ts` พอแล้ว
