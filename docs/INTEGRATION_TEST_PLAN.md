## 3. ขั้นตอน (ทำตามลำดับ หยุดรายงานทันทีถ้าขั้นไหนล้ม)

### A. Integration test เดิม + migration 008  (ไม่ต้องใช้ Gemini)
```bash
pnpm test        # ทั้งชุด รวม src/infrastructure/db/repos/repos.integration.test.ts (Testcontainers postgres:17-alpine)
```
ต้องผ่านทั้งหมด จุดที่ **ยังไม่เคยรันเลย** และต้องดูเป็นพิเศษ:
- migration `001`–`008` รันต่อกันบน DB ว่างได้ โดยเฉพาะ `008`
- เทสต์ `monthly summaries (AI cache)`: upsert แทนค่าเดิม, แยกบัญชี, `CHECK` เดือนผิดรูปแบบ (`2026-13`) ถูก DB ปฏิเสธ
- `pnpm db:rollback` แล้ว `pnpm db:migrate` ซ้ำ (008 `down` ต้อง DROP ได้สะอาด)

### B. เพิ่ม integration test ที่ยังขาด (ใส่ใน `repos.integration.test.ts` ตามแพทเทิร์นเดิม)
1. **`RecordBackfill` rollback จริง:** ส่ง 3 แถว โดยแถวที่ 3 ใช้ `categoryId`/`walletId` ของบัญชีอื่น (หรือ wallet ที่ไม่มี) → ต้อง throw และ `entries` ของบัญชีนั้น **ว่างเปล่า** (fake ทดสอบ rollback ไปแล้ว แต่ยังไม่เคยลองกับ transaction ของ Postgres)
2. **`RecordBackfill` นับ log ครั้งเดียว:** บันทึก 5 แถว → `logged_days` มีแค่วันนี้ 1 แถว, `xp` มี `first_log` ครั้งเดียว, ไม่มีแถว logged_days ของวันที่ย้อนหลัง
3. **`FindDuplicates` + `entries.onDay` จริง:** สร้าง entry เวลา `2026-09-28T23:30+07:00` และ `2026-09-29T00:30+07:00` → ต้องถูกจับคู่กับแถววัน 28 และ 29 ตามลำดับ (เช็กเขตเวลา Bangkok ที่ขอบเที่ยงคืน ซึ่ง fake ไม่ได้ทดสอบ)
4. **แยกบัญชี:** ผู้ใช้ B เรียก `FindDuplicates` ไม่เห็น entry ของผู้ใช้ A
5. **โควตา AI กับ DB จริง:** `spendAiBudget` ผ่าน `login_attempts` ด้วย key `ai:<userId>` — ครบ limit แล้วครั้งถัดไปได้ `RATE_LIMITED`, บัญชีอื่นไม่โดนกระทบ, `perDay: null` ยังนับแต่ไม่บล็อก

### C. Smoke test กับ dev server และ Gemini จริง
```bash
pnpm db:migrate && pnpm user:add            # สร้าง smoke@example.com (หรือแก้อีเมลใน scripts/smoke/*.py)
pnpm dev -p 3111                            # สคริปต์ smoke ยิงที่ http://localhost:3111
T_PW='<รหัสผ่าน>' python3 scripts/smoke/api.py
```
`scripts/smoke/receipt.py` ฮาร์ดโค้ดพาธรูปที่ `/tmp/claude-501/receipt.jpg` → แก้เป็นรูปจริงในเครื่อง

ยิง endpoint ใหม่ด้วย session เดียวกัน (ดู `call()` ใน `api.py`) ตรวจ **สถานะ HTTP และ shape**:

| endpoint | กรณี | คาดหวัง |
|---|---|---|
| `POST /api/backfill/check` | แถวตรงกับ entry ที่จดไว้ / ไม่ตรง / แถวซ้ำกันเอง | `{duplicates:[true,false,...]}` · 401/redirect เมื่อไม่ได้ login |
| `POST /api/backfill` | 3 แถวปกติ | 201, `entries.length===3` · แถว `total:0` → 422 · 61 แถว → 400/422 · `rows:[]` → 400/422 |
| `POST /api/entry/parse` | `{"text":"ข้าวมันไก่ 60 หารแฟน"}` | 200 draft (ใช้ AI จริง) · `text:""` → 422 `INVALID_TEXT` |
| `GET /api/summary?month=YYYY-MM` | เดือนที่มีรายจ่าย 2 ครั้งติด | ครั้งที่ 2 **ไม่เรียก AI** (cache) และนับโควตาเท่าเดิม · เดือนว่าง → ข้อความ "เดือนนี้ยังไม่มีรายจ่ายให้สรุป" โดยไม่เสียโควตา |
| `POST /api/receipt/parse` | รูปสลิป/ออเดอร์/ประวัติ/ที่ไม่ใช่เงิน | ดูตาราง D |

**โควตา:** ตั้ง `AI_DAILY_LIMIT=3` ใน `.env.local`, ยิง `/api/receipt/parse` 4 ครั้ง → ครั้งที่ 4 ได้ 429 `RATE_LIMITED`; ลอง `/api/summary` ที่ cache อยู่แล้ว → ยังตอบได้แม้โควตาหมด

### E. UI ในเบราว์เซอร์ (มือถือจริง หรือ Chrome DevTools โหมดมือถือ)
1. **วงล้อ:** มี 7 ช่อง "ประโยคเดียว" อยู่ครบ ไม่ทับกัน ลากเลือกได้ (วงล้อเดิมออกแบบไว้ 6 ช่อง)
2. **`/say`:** พิมพ์ → ร่าง → แก้ → บันทึก → toast "ย้อนกลับ" ลบได้ · ไมค์: ขอสิทธิ์/ปฏิเสธสิทธิ์/ไม่พูด (no-speech) แสดงข้อความไทยที่เข้าใจ · **iOS Safari และ PWA ที่ติดตั้งลงหน้าจอ**: ปุ่มไมค์ซ่อนหรือใช้ได้จริง (ไม่ค้าง)
3. **สแกน:** เลือก 1 รูปใบเสร็จ → หน้าตรวจรายการเดิม · เลือก 1 รูปประวัติ → หน้า "จดย้อนหลัง" · เลือก 3 รูป → แสดง "กำลังอ่านรูปที่ i/3" แล้วได้รายการรวม · มี 1 รูปที่อ่านไม่ได้ → ขึ้น "อ่านไม่ได้ 1 รูป" แต่รูปอื่นใช้ได้
4. **จดย้อนหลัง:** แถวที่ซ้ำไม่ถูกติ๊ก · แก้จำนวน (พิมพ์ `12.` ค้างไว้แล้วออกจากช่อง) · สลับ +/− แล้วหมวดรีเซ็ต · ใส่จำนวน 0 ในแถวที่ติ๊ก → ปุ่มบันทึกถูกปิด + ขึ้นข้อความ · บันทึกแล้วไปหน้าแรก ปฏิทินวันเก่ามียอด · กดย้อนกลับลบครบทุกแถว · streak/XP เพิ่มครั้งเดียว
5. **สแกนหารกัน + ออเดอร์เดลิเวอรี่:** เลือกแฟน → แถวค่าส่งเป็น "หาร" และสรุปล่างถูก (ค่าส่ง 25 บาท หาร 2 = 12.50 / 12.50) · ยอดค้างของแฟนในหน้า "ยอดค้าง" ถูกต้อง
6. **วิดเจ็ตสรุปเดือน:** เปิดแดชบอร์ดแล้วยังไม่มีการเรียก AI (ดู log) · กดปุ่มแล้วได้ข้อความ · บัญชีเดิมที่มี layout อยู่แล้วเห็นวิดเจ็ตใหม่ต่อท้าย · ซ่อน/เรียงได้ในหน้าตั้งค่า
7. **dark mode** ทุกหน้าใหม่ (`/say`, หน้าจดย้อนหลัง, วิดเจ็ต)
