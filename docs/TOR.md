# me-budget — TOR / Requirements (v0.2)

## Context
อยากได้เว็บแอปบันทึกรายรับ-รายจ่ายส่วนตัวไว้ใช้ทุกวัน เจ้าของขี้เกียจจด เลยต้อง **กดบันทึกให้ได้เร็วที่สุด**
ปกติจ่ายเงินแทนแฟนไปก่อนบ่อย (เช่น ข้าว 100 บาท ส่วนของแฟน 50) ระบบเลยต้องรองรับเรื่องนี้ตรงๆ
แล้วก็อยากมี **gamification + noti** ไว้กระตุ้นตัวเองให้กลับมาจดทุกวัน
ตอนนี้โฟลเดอร์ `/Users/phurikorn/hobby/me-budget/` ยังว่างอยู่ เอกสารนี้เน้นว่า "ระบบต้องทำอะไรได้บ้าง" ส่วน tech จะเขียนไว้แค่ข้อจำกัดหลักในหัวข้อ 1

---

## 1. ขอบเขต
- **ผู้ใช้:** ใช้คนเดียว (ตัดสินใจแล้ว) แฟนไม่ต้องใช้แอป เราจดเองแล้วเคลียร์ยอดเอง
- **อุปกรณ์หลัก:** มือถือ (mobile-first) เปิดผ่านเว็บแล้วติดตั้งลงหน้าจอเป็นแอปได้
- **ภาษา/สกุลเงิน:** ภาษาไทย ใช้เงินบาท (THB) อย่างเดียว
- **แพลตฟอร์ม (ตัดสินใจแล้ว):** Next.js deploy บน Vercel และเก็บข้อมูลบน cloud → เปิดได้หลายเครื่อง ข้อมูลไม่หายเวลาเปลี่ยนมือถือ
- **Auth (ตัดสินใจแล้ว):** login ด้วย **email + password** (เดิมเลือก Google sign-in แต่เปลี่ยนเป็นแบบนี้ "ไปก่อน") ผู้ใช้มีคนเดียวโดยบัญชีกำหนดในระบบ ล็อกอินผิดซ้ำจะถูกจำกัดความพยายาม session ยาว 90 วัน เปิดแอปแล้วเจอแป้นตัวเลขทันที ไม่ต้องเจอหน้า login

## 2. Functional Requirements

### FR-1 บันทึกเร็ว (หัวใจของแอป)
- **หน้าแรกเป็น dashboard (ตัดสินใจแล้ว)** ประกอบด้วย widget ที่ปรับแต่งได้ (ดู FR-11) มีปุ่ม **[+]** ลอยอยู่มุมล่าง อยู่ในระยะนิ้วโป้ง
- **วงล้อเลือกโหมด สไตล์ GTA V (ตัดสินใจแล้ว):**
  - **แตะ [+] สั้นๆ** → เข้าหน้าจดรายจ่ายทันที (ทางลัดของเคสที่ใช้บ่อยที่สุด)
  - **กด [+] ค้าง** (~250ms) → มีวงล้อเด้งขึ้นรอบนิ้ว แต่ละช่องคือโหมดการจด **ลากนิ้วไปที่ช่อง** ช่องนั้นจะขยายและไฮไลต์ แล้ว**ปล่อยนิ้ว** เพื่อเข้าโหมดนั้น
  - ปล่อยนิ้วตรงกลางวงล้อหรือลากออกนอกวง → ยกเลิก
  - มี haptic สั่นเบาๆ ตอนลากเปลี่ยนช่อง (ถ้าเครื่องรองรับ) และ animation ต้องลื่น
  - **ช่องในวงล้อมี 6 ช่อง (ตัดสินใจแล้ว — Claude เลือกให้)** เรียงตามเข็มนาฬิกาเริ่มจากด้านบน:
    1. `payments` **รายจ่าย** (ด้านบน ลากถึงง่ายสุด)
    2. `savings` **รายรับ**
    3. `group` **ออกก่อนแฟน** → เข้าหน้าจดรายจ่ายที่เปิด toggle ออกก่อนแฟนไว้แล้ว และตั้งเป็นหารไว้ก่อน
    4. `currency_exchange` **แฟนจ่ายคืน** → เข้าหน้าใส่ยอด ค่าเริ่มต้นคือยอดแฟนติดทั้งหมด (ช่องนี้เป็นสีเทา กดไม่ได้ถ้ายอดแฟนติด = 0)
    5. `bedtime` **ไม่ได้ใช้เงิน** → กดแล้วบันทึกทันที ไม่มีหน้าถัดไป (ช่องนี้เป็นสีเทา กดไม่ได้ถ้าวันนี้จดไปแล้ว)
    6. `photo_camera` **สแกนใบเสร็จ** → เปิดกล้องทันที
  - ช่องที่กดไม่ได้จะ**เป็นสีเทาแทนการซ่อน** ช่องจะได้อยู่ตำแหน่งเดิมเสมอ จนกล้ามเนื้อจำได้เอง
- flow ปกติ: **แตะ [+] → พิมพ์ยอด → แตะหมวด → เสร็จ** (แตะหมวดแล้วบันทึกเลย ไม่มีปุ่มบันทึกแยก) ใช้เวลาไม่เกิน 5 วินาที
- ค่าเริ่มต้น: วันที่ = วันนี้, ประเภท = รายจ่าย ส่วนโน้ตใส่หรือไม่ใส่ก็ได้
- หมวดที่ใช้บ่อยขึ้นมาอยู่ข้างหน้าเอง
- **ปุ่มลัด (Preset)** (ตัดสินใจแล้ว — Claude เลือกให้):
  - **MVP:** แถวปุ่มลัดอยู่บน dashboard **แตะครั้งเดียวจดเลย** เช่น [icon `train` BTS 47] หรือ [icon `restaurant` ข้าวเที่ยง 60] โชว์ 3–4 ปุ่มแล้วเลื่อนซ้าย-ขวาดูที่เหลือ ตั้งค่า เพิ่ม ลบ และเรียงลำดับเองได้ ปุ่มลัดตั้งให้เป็นออกก่อนแฟนได้ด้วย
  - **v1.1:** ระบบเสนอปุ่มลัดเองจากรายการที่จดซ้ำ (ยอด + หมวด + โน้ตเดียวกัน ตั้งแต่ 3 ครั้งขึ้นไปใน 14 วัน) เช่น "จด BTS 47 บ่อยนะ ทำเป็นปุ่มลัดไหม?"
- หลังบันทึกทุกครั้ง (รวมถึงจากปุ่มลัด) จะมีแถบ "จดแล้ว · ย้อนกลับ" ขึ้นมาให้กด undo ได้ภายใน 5 วินาที

### FR-2 รายรับ / รายจ่าย
- เลือกรายรับหรือรายจ่ายได้จากวงล้อ และในหน้าจดก็สลับได้ด้วย
- แก้ไขและลบรายการย้อนหลังได้

### FR-3 ออกก่อนแฟน ⭐
- ในหน้าบันทึกมีปุ่ม toggle **"ออกก่อนแฟน"** กดแล้วเลือกแบบแบ่งได้:
  - **ครึ่งๆ** (ค่าเริ่มต้น): จ่าย 100 → ของเรา 50, แฟนติด 50
  - **ของแฟนทั้งหมด**: แฟนติด 100
  - **กรอกยอดเอง**: ใส่ส่วนของแฟนเป็นตัวเลข
- **กฎทางบัญชี:** นับเป็นรายจ่ายของเราแค่ส่วนของเราเท่านั้น ส่วนของแฟนไปเพิ่มใน "ยอดแฟนติด" ไม่ไปทำให้งบเรากระเด็น
- หน้าแรกแสดง **"แฟนติดเรา ฿xxx"** ให้เห็นตลอด
- **เคลียร์ยอด:** กด "แฟนจ่ายคืน" แล้วใส่ยอด จะคืนครบหรือคืนบางส่วนก็ได้ เงินที่แฟนจ่ายคืนไม่นับเป็นรายรับ
- แฟนจ่ายคืนจะหักจากยอดรวมเสมอ ไม่ต้องเลือกว่าคืนค่าอะไร
- กดดูได้ว่ายอดที่ยังค้างมาจากรายการไหนบ้าง (ระบบคำนวณแบบหักรายการเก่าสุดก่อน)

### FR-4 หมวดหมู่
- มีหมวดตั้งต้นพร้อม **icon (Google Material Symbols ไม่ใช้ emoji)** เช่น อาหาร เดินทาง ช้อปปิ้ง บิล บันเทิง สุขภาพ อื่นๆ / เงินเดือน รายได้อื่น
- เพิ่ม แก้ไข และเรียงลำดับหมวดเองได้

### FR-5 งบประมาณ (Budget planning)
- ตั้งงบต่อเดือนได้ ทั้งงบรวมและงบรายหมวด
- หน้าแรกแสดง **"วันนี้ใช้ได้อีก ฿xxx"** คิดจาก (งบที่เหลือ ÷ จำนวนวันที่เหลือในเดือน)
- มี progress bar ต่อหมวด เปลี่ยนเป็นสีเตือนเมื่อใช้เกิน 80% และ 100%

### FR-6 สรุปและประวัติ
- ดูรายการเรียงตามวัน พร้อมยอดรวมของแต่ละวัน (หรือดูแบบปฏิทินผ่าน widget ใน FR-11)
- สรุปรายสัปดาห์และรายเดือน: รายรับ รายจ่าย คงเหลือ และกราฟแยกตามหมวด
- กรองตามหมวด หรือดูเฉพาะรายการ "ออกก่อนแฟน" ได้

### FR-7 Gamification 🎮
- **Streak รายวัน:** วันนั้นนับว่า "จดแล้ว" ถ้า**ในวันนั้นจริงๆ** เรากดจดรายการอย่างน้อย 1 รายการ **หรือ** กด "วันนี้ไม่ได้ใช้เงิน" (มีปุ่มนี้ไว้ให้ไม่ต้องใช้เงินเพื่อรักษา streak)
  - **(ตัดสินใจแล้ว)** นับจาก**เวลาที่กดจด** ไม่ใช่วันที่ของรายการ การจดย้อนหลังจะบันทึกเงินได้ตามปกติ แต่**ไม่คืน streak**
  - "ไม่ได้ใช้เงิน" กดได้เฉพาะของวันนี้เท่านั้น
  - วันตัดรอบคือเที่ยงคืน เวลาไทย (Asia/Bangkok)
- **XP + Level** (ตัดสินใจแล้ว — Claude เลือกให้): XP หลักมาจาก**วันที่จดแล้ว** ไม่ได้มาจากจำนวนรายการ เพื่อกันการปั๊ม XP
  - จดครั้งแรกของวัน หรือกด "ไม่ได้ใช้เงิน" ได้ **+10**
  - ตัวคูณตาม streak: ตั้งแต่ 7 วันขึ้นไป ×1.5, ตั้งแต่ 30 วันขึ้นไป ×2 (คูณเฉพาะ +10 ของวันนั้น)
  - จดรายการเพิ่มในวันเดียวกันได้ +1 ต่อรายการ แต่ได้สูงสุด +5 ต่อวัน (สแกนใบเสร็จ 1 ใบนับเป็น 1 รายการ)
  - ยอดแฟนติดลดลงจนเป็น 0 ได้ **+20**
  - (v1.1 ทำพร้อมงบ) วันที่ใช้ไม่เกินงบรายวันได้ +5
  - Level: เลื่อนจาก Lv n ไป n+1 ต้องใช้ 100 × n XP
  - XP สะสมไปเรื่อยๆ **ไม่มีวันลดลง** ถึง streak ขาดก็ยังมีความคืบหน้าเหลืออยู่
  - ลบรายการทิ้ง: ไม่ดึง XP หรือ streak คืน (เป็นแอปส่วนตัว ไม่ต้องกันการโกง)
- **Streak freeze (ตัวกันหลุด):** สะสมได้ 1 อันต่อ 7 วันติด เอาไว้กันขาดได้ 1 วัน
- **Badges:** เช่น จดครบ 7/30/100 วัน, เคลียร์หนี้แฟนจนเป็น 0, ใช้ไม่เกินงบทั้งเดือน, No-spend day 5 วัน
- มีเอฟเฟกต์ตอนบันทึกสำเร็จ (confetti หรือ +XP เด้งขึ้นมา) แต่ต้องไม่ทำให้ช้าลง
- (ไว้รุ่นหลัง) สัตว์เลี้ยงหรือมาสคอตที่โตตาม streak, challenge รายสัปดาห์
- **ใน MVP มี:** streak, ไม่ได้ใช้เงิน, XP/Level, แถบเตือนในแอป และเอฟเฟกต์ +XP

### FR-10 สแกนใบเสร็จ + AI แยกว่าของใคร 🧾🤖 — อยู่ใน MVP
ใช้กรณีซื้อของร้านสะดวกซื้อหรือซูเปอร์ฯ ที่มีหลายรายการในบิลเดียว ขี้เกียจนั่งไล่อ่านเอง
- **Input:** ถ่ายรูปหรือเลือกรูปใบเสร็จจากในเครื่องได้ทั้งคู่ ปุ่มสแกนอยู่ข้างแป้นตัวเลขในหน้าบันทึก
- **AI อ่านใบเสร็จ** (Google Gemini vision) แล้วดึงข้อมูลออกมา:
  - ชื่อร้าน วันที่/เวลา และยอดรวมสุทธิ
  - รายการสินค้า: `ชื่อในบิล`, **`ชื่อกลาง`** (ชื่อสั้นที่คนอ่านเข้าใจ เช่น "นมเปรี้ยว") จำนวน และราคา
    - ตอนเรียก AI ให้ส่งรายการชื่อกลางที่มีอยู่ในความจำไปด้วย เพื่อให้ AI เลือกใช้ชื่อเดิมซ้ำก่อนตั้งชื่อใหม่
  - ส่วนลด/โปรโมชั่น และ VAT ถ้ามี
  - หมวดของแต่ละรายการ (เดาให้)
- **AI เดาเจ้าของแต่ละบรรทัด** ว่าเป็น `เรา` / `แฟน` / `หาร` โดยไล่ลำดับแบบนี้ (ตัดสินใจแล้ว):
  1. **ความจำเจ้าของ** (จับคู่ด้วย `ชื่อกลาง`): ถ้าเคยแก้สินค้านี้มาก่อน ให้ใช้ตามที่เคยแก้ เช่น เคยตั้ง "นมเปรี้ยว" เป็นของแฟน ครั้งหน้าก็เดาว่าเป็นของแฟน (ความจำนี้ชนะเสมอ)
  2. **AI เดาจากสามัญสำนึก:** ใช้ชนิดสินค้าประกอบกับ **"โน้ตเกี่ยวกับแฟน"** ที่ตั้งไว้ในหน้าตั้งค่า (เช่น "แฟนชอบนมเปรี้ยว ไม่กินเผ็ด") ซึ่งส่งให้ AI ทุกครั้ง
  3. ถ้า AI ไม่มั่นใจ → ใส่เป็น `เรา` แล้ว**ไฮไลต์บรรทัดนั้นให้เห็นว่าเป็นการเดา**
  - ไม่ต้องแม่น 100% ยอมรับได้ว่าจะผิดบ้าง
- **หน้าตรวจ/แก้ (สำคัญที่สุด ต้องแก้ได้ง่าย):**
  - บรรทัดที่ AI ไม่มั่นใจ (ข้อ 3 ด้านบน) จะถูกไฮไลต์ ดูแค่บรรทัดพวกนี้ก็พอ
  - แสดงรายการเป็นลิสต์ แต่ละบรรทัดโชว์ `ชื่อกลาง` (แตะดู `ชื่อในบิล` ได้) และมีชิปเจ้าของ **แตะ 1 ครั้งเพื่อวนเปลี่ยน** เรา → แฟน → หาร
  - มีปุ่มลัด "ทั้งหมดของเรา", "ทั้งหมดของแฟน" และ "หารทั้งบิล"
  - หมวดไม่ได้โชว์ในลิสต์ ถ้าแตะบรรทัดจะเปิดรายละเอียดขึ้นมา ซึ่งมีหมวดและชื่อในบิลให้ดู/แก้
  - แตะที่ชื่อหรือราคาเพื่อแก้ได้เลยในบรรทัด ปัดเพื่อลบ และเพิ่มรายการที่ AI อ่านตกได้
  - ด้านล่างสรุปสดทุกครั้งที่แก้: **ของเรา ฿x · ของแฟน ฿y · รวม ฿z**
  - ถ้าผลรวมรายการไม่ตรงกับยอดในบิล ให้ขึ้นเตือนให้เห็นชัด (AI อาจอ่านผิด)
  - กดบันทึกครั้งเดียวจบ
- **วิธีบันทึกลงบัญชี:** (ตัดสินใจแล้ว: 1 ใบเสร็จ = 1 รายการ มีบรรทัดใบเสร็จอยู่ข้างใน และสรุปตามหมวดคิดจากแต่ละบรรทัด)
  - ส่วนของเรา = รายจ่าย แยกตามหมวด
  - ส่วนของแฟน = เพิ่มเข้า "แฟนติดเรา" (ใช้ logic เดียวกับ FR-3)
  - ส่วนลดหรือ VAT ระดับบิลจะเฉลี่ยตามสัดส่วนราคาของแต่ละรายการ
- **Fallback:**
  - ถ้า AI ล้มเหลวหรือไม่มีเน็ต → ให้กรอกยอดรวมเอง แล้วเข้า flow ปกติของ FR-1/FR-3
  - ถ้ารูปไม่ชัด → แจ้งให้ถ่ายใหม่
- **รูป (ตัดสินใจแล้ว): ไม่เก็บรูป** ส่งรูปไปให้ API ประมวลผลแล้วรับ JSON กลับมา หลังจากนั้นทิ้งรูปทันที สิ่งที่เก็บมีแค่ข้อมูลที่อ่านได้ คือร้าน วันที่ บรรทัดใบเสร็จ และเจ้าของ
- **ข้อจำกัด:**
  - API key ต้องเก็บไว้ฝั่ง server (Next.js route บน Vercel) ห้ามฝังไว้ในหน้าเว็บ และ route นี้ต้องเรียกได้เฉพาะตอน login แล้ว
  - ต้องคุมค่าใช้จ่าย เช่น จำกัดจำนวนครั้งต่อวัน และย่อรูปก่อนส่ง
  - รูปใบเสร็จจะถูกส่งออกไปให้ Google ประมวลผล แต่ไม่ถูกเก็บไว้ในระบบเรา
- **Gamification:** สแกนใบเสร็จได้ XP เท่ากับการจดปกติ (FR-7)

### FR-11 Dashboard แบบ widget ปรับแต่งได้ 🧩 — อยู่ใน MVP
- dashboard ประกอบด้วย **widget** หลายตัว เลือกเองได้ว่าจะเปิดหรือปิดตัวไหน และเรียงลำดับเองได้
- **ระดับการปรับแต่ง (ตัดสินใจแล้ว):** มีหน้า "แก้ dashboard" เป็นลิสต์ widget แต่ละตัวมีสวิตช์เปิด/ปิด และลากขึ้นลงเพื่อเรียงลำดับ widget ทุกตัวกว้างเต็มจอ ขนาดเดียว และเรียงลงมาเป็นแนวตั้ง ไม่มีการลากย้ายหรือปรับขนาดแบบ iOS home screen
- **ส่วนที่ไม่ใช่ widget (อยู่ที่เดิมเสมอ):** ปุ่ม [+] และแถบเตือน "streak จะหลุด"
- **widget ที่มีใน MVP:**
  - 🔥 **Streak & Level:** streak, Lv และ progress bar ของ XP
  - 👫 **ยอดแฟนติด:** แตะเพื่อดูยอดค้างตามรายการ
  - ⚡ **ปุ่มลัด:** แถวปุ่มลัดแบบแตะครั้งเดียวจด
  - 💸 **วันนี้:** ใช้ไปเท่าไร และรับมาเท่าไรวันนี้
  - 📅 **ปฏิทิน:** ดูรายละเอียดด้านล่าง
  - 🧾 **รายการล่าสุด:** 5 รายการล่าสุด
- **widget ใน v1.1:** 🎯 วันนี้ใช้ได้อีก (FR-5), 📊 สัดส่วนตามหมวดของเดือนนี้, 🏅 เหรียญล่าสุด
- **ค่าเริ่มต้นตอนเปิดแอปครั้งแรก:** Streak & Level → ยอดแฟนติด → ปุ่มลัด → ปฏิทิน → รายการล่าสุด
- การตั้งค่าเลย์เอาต์เก็บบน cloud → มือถือกับคอมเห็นเลย์เอาต์เดียวกัน

#### 📅 widget ปฏิทิน
- แสดงตารางเดือนปัจจุบัน ปัดซ้าย-ขวาเพื่อเปลี่ยนเดือน
- **รูปแบบช่องวัน (ตัดสินใจแล้ว — Claude เลือกให้):**
  - บรรทัดบนเป็น **ยอดจ่ายสีแดง** (`-320`) บรรทัดล่างเป็น **ยอดรับสีเขียว** (`+15k`) และจะโชว์บรรทัดรับเฉพาะวันที่มีรายรับ
  - ยอดตั้งแต่ 1,000 ขึ้นไปย่อเป็น `k` (ทศนิยม 1 ตำแหน่ง)
  - สีพื้นของช่องเข้มขึ้นตามยอดจ่าย (heatmap) โดยเทียบกับวันที่จ่ายเยอะที่สุดในเดือนนั้น
  - ยอดจ่ายนับแค่ **ส่วนของเรา** และ **แฟนจ่ายคืน** ไม่นับเป็นรายรับ
  - ใต้ตารางมีแถวสรุปของเดือน: จ่าย ฿x · รับ ฿y · คงเหลือ ฿z
- วันที่นับเป็นวันที่จดแล้วมี icon `local_fire_department` เล็กๆ ส่วนวันไม่ใช้เงินมี icon `bedtime`
- แตะที่วัน → เปิด sheet รายการของวันนั้น พร้อมยอดรวมรับ/จ่าย และมีปุ่ม "+ จดของวันนี้" (กรณีวันในอดีตจะเป็นการจดย้อนหลัง ไม่ได้ streak ตาม D8)
- ยอดในปฏิทินใช้ **วันที่ของรายการ** (`occurredAt`) ส่วน icon ไฟใช้ **เวลาที่กดจด** (`createdAt`)

## 3. Non-functional
- mobile-first ใช้มือเดียวได้ ปุ่มหลักอยู่ในระยะนิ้วโป้ง
- เปิดแอปแล้วพร้อมพิมพ์ภายใน 1 วินาที
- ดีไซน์เรียบง่าย ทุกหน้าโฟกัสแค่เรื่องเดียว มี dark mode
- **ไอคอน (ตัดสินใจแล้ว):** ใช้ Google Material Symbols (Rounded) แทน emoji ทั้งหมดใน UI ส่วนตารางที่มี emoji ในเอกสารนี้เป็นแค่ตัวช่วยอ่าน ไม่ใช่ UI จริง ชื่อ icon ที่ใช้ดู DESIGN.md
- **แนวดีไซน์:** ได้แรงบันดาลใจจาก brilliant.org คือพื้นขาว ปุ่มแคปซูล 3D และการ์ดโค้ง ผสมความขี้เล่นแบบ Duolingo รายละเอียดอยู่ใน [DESIGN.md](DESIGN.md)
- ข้อมูลเป็นของเราเองล้วนๆ ไม่ผูกกับบัญชีธนาคาร

## 7. Acceptance scenarios (ไว้ตรวจตอนทำเสร็จ)
- เปิดแอป → แตะปุ่มลัด [BTS 47] → จดเสร็จใน 1 แตะ มีแถบ undo ขึ้นมา 5 วินาที
- จดค่าข้าว 60 บาท: เปิดแอป → แตะ [+] → พิมพ์ 60 → แตะหมวด "อาหาร" → บันทึกเสร็จ และกลับมาที่ dashboard
- กด [+] ค้าง → วงล้อขึ้น → ลากไป "รายรับ" → ปล่อยนิ้ว → เข้าหน้าจดรายรับ
- กด [+] ค้าง แล้วปล่อยตรงกลาง → วงล้อปิด ไม่มีอะไรเกิดขึ้น
- วันที่ 4 ข้าว 100 ออกก่อนแฟนแบบหาร + เงินเดือนเข้า 15,000 → ช่องวันที่ 4 ในปฏิทินโชว์ `-50` และ `+15k`
- ปิด widget ปุ่มลัด แล้วย้ายปฏิทินขึ้นไปบนสุด → เปิดในคอมก็เห็นเลย์เอาต์เดียวกัน
- ข้าว 100 บาท ออกก่อนแฟนแบบครึ่งๆ: รายจ่ายวันนี้ +50 และ "แฟนติดเรา" +50
- แฟนคืน 30: ยอดแฟนติดเหลือ 20 และรายรับไม่เปลี่ยน
- วันนี้ยังไม่ได้จด: เปิดแอปมาเจอแถบ "streak กำลังจะหลุด" แต่ถ้าจดแล้วแถบนี้หายไป
- จดในมือถือ แล้วเปิดในคอม: เห็นรายการเดียวกัน
- ยังไม่ login: เข้าหน้าไหนไม่ได้เลย รวมถึงเรียก API สแกนใบเสร็จด้วย
- ล็อกอินด้วยอีเมลหรือรหัสผ่านผิด: ถูกปฏิเสธด้วยข้อความเดียวกัน และผิดซ้ำหลายครั้งจะถูกจำกัดชั่วคราว
- login ไว้แล้ว กลับมาเปิดแอปอีกครั้งใน 90 วัน: เข้าหน้าจดได้เลย ไม่ต้อง login ใหม่
- กด "วันนี้ไม่ได้ใช้เงิน": streak +1 และไม่มีรายการ 0 บาทโผล่ในประวัติ
- วันที่ streak = 10 จดรายการแรกของวันได้ +15 XP (10 × 1.5) จดเพิ่มอีก 8 รายการได้แค่ +5 (ชนเพดาน)
- เมื่อวานลืมจด วันนี้จดรายการของเมื่อวานย้อนหลัง: เงินถูกบันทึก แต่ streak ยังขาดเหมือนเดิม (ยกเว้นมีตัวกันหลุดเหลืออยู่)
- สแกนบิล 7-11 ที่มี 5 รายการ: AI ดึงออกมาครบ, แตะเปลี่ยน 2 รายการเป็น "แฟน", กดบันทึก → รายจ่ายเพิ่มเท่าส่วนของเรา และ "แฟนติดเรา" เพิ่มเท่าส่วนของแฟน
- บิลแรกที่ยังไม่มีความจำเจ้าของ: AI เดาจากโน้ตเกี่ยวกับแฟนและชนิดสินค้า บรรทัดที่ไม่มั่นใจถูกไฮไลต์และตั้งเป็น `เรา`
- ครั้งก่อนตั้ง "ดัชมิลล์ นมเปรี้ยว สตรอ" เป็นของแฟน พอสแกนบิลใหม่ที่มี "DUTCHMILL YOG BLUEBERRY" ได้ชื่อกลาง "นมเปรี้ยว" เหมือนกัน และ AI เดาว่าเป็นของแฟนให้เอง
- ผลรวมรายการไม่ตรงกับยอดบิล: ขึ้นเตือน และยังแก้หรือบันทึกต่อได้
