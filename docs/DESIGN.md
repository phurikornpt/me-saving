# me-budget — Design Language

แนวทางนี้ได้แรงบันดาลใจหลักจาก [brilliant.org/topics/coding](https://brilliant.org/topics/coding/) **ผสมความขี้เล่นแบบ Duolingo นิดหน่อย**
**ใช้เป็นแรงบันดาลใจเท่านั้น** ห้ามเอาโลโก้ ฟอนต์ลิขสิทธิ์ของเขา (CoFo) หรือภาพประกอบมาใช้ตรงๆ ให้ถอดเอาแค่ "ภาษา" ของดีไซน์

## ส่วนผสม Duolingo
- ปุ่ม 3D **หนาและนูนกว่า Brilliant** เล็กน้อย (`--press-depth: 4px` → 5px บนปุ่มหลัก)
- ตัวหนังสือหัวข้อและตัวเลขเงินใช้ **sans แบบกลมมน หนา** แทน serif ให้ดูเป็นมิตรเหมือน Duolingo (ฟอนต์ serif ภาษาไทยก็ไม่ค่อยเข้ากับ UI แบบเกมอยู่แล้ว)
- **หน้าฉลองเต็มจอ** ตอน streak ถึงหลักสำคัญ (7/30/100 วัน) หรือตอนเลเวลอัป: ก้อน icon `local_fire_department` ตัวใหญ่เด้งขึ้นมา พร้อม confetti และปุ่ม "ไปต่อ" ตัวโต
- แถบเตือน streak และข้อความให้กำลังใจใช้ภาษาเล่นๆ เช่น "ไฟจะดับแล้วนะ จดสักอย่างเหอะ" (พร้อม icon `local_fire_department`)
- (v1.2) มาสคอตตัวเล็กๆ บน dashboard ที่แสดงอารมณ์ตาม streak

## ฟอนต์ (ตัดสินใจแล้ว — Claude เลือกให้ เปลี่ยนได้)
- **หัวข้อภาษาไทย:** `Mitr` (Google Fonts) น้ำหนัก 500–600 กลมมน หนา ขี้เล่น ให้ฟีล Duolingo ใช้ **เฉพาะหัวข้อภาษาไทย** (class `font-display` เช่น ชื่อหน้า, หัว sheet) ไม่ใช้กับตัวเลข
- **ตัวเลขทุกที่ (ยอดเงิน, ตัวนับ, streak, XP):** `Anuphan` ตัวหนา (700, `font-bold`) เพราะ Mitr ใส่ขีดเฉียงในเลข 0 (เห็นเป็น "Ø") อ่านเป็นตัวเงินได้ไม่ดี (พบตอนทดสอบหน้าจริง)
- **UI + เนื้อหา:** `Anuphan` (Google Fonts) น้ำหนัก 400/500 อ่านง่าย ทันสมัย
- ตัวเลขทุกที่ใช้ `font-variant-numeric: tabular-nums` ให้หลักตรงกันในลิสต์และปฏิทิน

## ไอคอน (ตัดสินใจแล้ว: Google Material Symbols แทน emoji)
- ใช้ **Material Symbols Rounded** (variable font จาก Google Fonts) ไม่ใช้ emoji ใน UI เพื่อให้หน้าตาเหมือนกันทุกเครื่องและควบคุมสี/น้ำหนักได้
- ใช้ผ่าน ligature: `<span class="material-symbols-rounded">restaurant</span>` ขนาด 24px เป็นค่าเริ่มต้น (ปุ่ม [+] และวงล้อ 28–32px)
- **สถานะ outline/fill:** ปกติ `FILL 0` ส่วนตัวที่ถูกเลือกหรือ "ติดแล้ว" เช่น streak ที่จดแล้ว ใช้ `FILL 1`
- **ระวัง ligature โชว์เป็นข้อความ:** ก่อนฟอนต์โหลดเสร็จ คำอย่าง `restaurant` จะโผล่เป็นตัวหนังสือ จึงใช้ `display=block` ในลิงก์ฟอนต์ (ตัวอักษรจะถูกซ่อนไว้จนฟอนต์พร้อม)
- **ขนาดไฟล์:** โหลดเป็น **subset** เฉพาะ icon ที่ใช้ ผ่านลิงก์ Google Fonts (`family=Material+Symbols+Rounded:opsz,wght,FILL,GRAD@24,400,0..1,0&icon_names=...&display=block`) ที่ประกอบจากรายชื่อใน `src/client/icons.ts` (`iconFontUrl()` ใส่ใน `<head>` ของ `layout.tsx`) ถ้าจะใช้ icon ใหม่ให้เพิ่มชื่อในลิสต์นั้น (เรียงตามตัวอักษร) ไม่งั้นจะไม่ถูกโหลด และ `<Icon>` จะแสดง `more_horiz` แทนชื่อที่ไม่รู้จัก ชุด icon ที่ผู้ใช้เลือกให้หมวด/ปุ่มลัดได้คือ `ICON_CHOICES` ในไฟล์เดียวกัน
- ในฐานข้อมูลเก็บเป็น **ชื่อ icon** (คอลัมน์ `icon`) ผู้ใช้เลือก icon ให้หมวด/ปุ่มลัดจากชุดที่เราเตรียมไว้ ไม่ต้องพิมพ์เอง

| ที่ | icon |
|---|---|
| ปุ่ม [+] | `add` |
| วงล้อ: รายจ่าย / รายรับ | `arrow_upward` / `arrow_downward` ในวงกลมสีส้ม/เขียว (หรือ `payments` / `savings`) |
| วงล้อ: ออกก่อนแฟน | `group` |
| วงล้อ: แฟนจ่ายคืน | `currency_exchange` |
| วงล้อ: ไม่ได้ใช้เงิน | `bedtime` |
| วงล้อ: สแกนใบเสร็จ | `photo_camera` (หรือ `receipt_long`) |
| Streak / เตือน streak | `local_fire_department` |
| XP / Level | `bolt` / `military_tech` |
| ยอดแฟนติด | `favorite` |
| ปฏิทิน / รายการล่าสุด | `calendar_month` / `history` |
| undo | `undo` |
| หมวดตั้งต้น | อาหาร `restaurant` · เดินทาง `train` · ช้อปปิ้ง `shopping_bag` · บิล `receipt` · บันเทิง `movie` · สุขภาพ `health_and_safety` · อื่นๆ `more_horiz` · เงินเดือน `account_balance_wallet` · รายได้อื่น `savings` |

## Design tokens (ร่าง)
```css
:root {
  /* พื้นและตัวอักษร */
  --bg: #FFFFFF;
  --surface: #F5F3F1;          /* พื้นเทาอุ่นของ dashboard */
  --card: #FFFFFF;
  --text: #000000;
  --text-2: rgba(0,0,0,.6);
  --text-3: rgba(0,0,0,.4);
  --line: rgba(0,0,0,.1);

  /* สีที่มีความหมาย */
  --primary: #29CC57;          /* ปุ่มหลัก และการกระทำ */
  --primary-edge: #15B441;     /* เงาแข็งใต้ปุ่ม */
  --income: #1FA34A;           /* รายรับ: เขียวเข้มกว่า primary จะได้ไม่ปนกับปุ่ม */
  --expense: #F2603D;          /* รายจ่าย: ส้มคอรัล */
  --partner: #456DFF;          /* อะไรที่เกี่ยวกับแฟน: ยอดแฟนติด, ชิป "แฟน" */
  --streak: #D7F25A;           /* ก้อน streak สีเหลืองมะนาว */
  --xp: #8B6CFF;               /* XP / Level */

  /* รูปทรง */
  --radius-pill: 9999px;
  --radius-card: 24px;
  --radius-section: 32px;
  --press-depth: 4px;          /* ความลึกของปุ่ม 3D */
}
```
- **ปุ่ม 3D:** ตอนปกติใช้ `transform: translateY(-4px)` คู่กับ `box-shadow: 0 4px 0 var(--edge)` พอกด (`:active`) ให้ `translateY(0)` และ `box-shadow: none` จะรู้สึกเหมือนกดปุ่มจริง
- **Dark mode:** พื้น `#111` / การ์ด `#1C1C1E` / ตัวอักษรขาว สีความหมายใช้ชุดเดิมแต่สว่างขึ้นประมาณ 10% ทำด้วย `@media (prefers-color-scheme: dark)` ใน `globals.css` ตามค่าของเครื่องอัตโนมัติ (ยังไม่มีสวิตช์สลับเอง)

## Component → แนวดีไซน์
| Component | แนวทาง |
|---|---|
| ปุ่ม [+] | วงกลมสีเขียว 3D ใหญ่ 64px ลอยอยู่มุมล่าง พอกดค้างตัวปุ่มยุบลง แล้ววงล้อกางออก |
| วงล้อ GTA | พื้นหลังเบลอและมืดลง ช่องเป็นการ์ดขาวรูปพาย ช่องที่นิ้วชี้อยู่ขยายขึ้นและเป็นพื้นดำตัวอักษรขาว (สไตล์เดียวกับชิปที่ถูกเลือก) ช่องที่ใช้ไม่ได้ลดความทึบเหลือ 30% |
| แป้นตัวเลข | ปุ่มขาว 3D มีเงาแข็ง `#E5E2DE` ตัวเลข sans ขนาดใหญ่ |
| ยอดเงินที่กำลังพิมพ์ | **Anuphan bold ตัวใหญ่ (`text-6xl` ≈ 60px)** เป็นตัวเอกของหน้าจด (ไม่ใช้ Mitr เพราะเลข 0) ใต้ยอดมีบรรทัดแสดง "ของเรา ฿x · แฟนติด ฿y" ที่จองที่ไว้เสมอ |
| ชิปเจ้าของ | แคปซูล: เรา = ดำ, แฟน = `--partner`, หาร = ครึ่งดำครึ่งน้ำเงิน |
| Widget | การ์ดขาว radius 24 วางบน `--surface` หัวการ์ดเป็น Anuphan 14 สีเทา และตัวเลขหลักเป็น Anuphan bold |
| Widget Streak | ก้อนกลม 3D ของ 7 วัน วันที่จดแล้วเป็นสีเหลืองมะนาวพร้อม icon `local_fire_department` (แบบ fill) วันที่ขาดเป็นสีเทา และวันนี้มีขอบกะพริบถ้ายังไม่จด |
| ปฏิทิน | ช่องวันโค้ง 12px ใช้ heatmap สีคอรัลอ่อนไปเข้ม `-320` เป็นสีคอรัล `+15k` เป็นสีเขียว |
| แถบเตือน streak | แคปซูลสีเหลืองมะนาว ตัวอักษรดำ มี icon `local_fire_department` |
| แถบ undo | แคปซูลดำลอยอยู่ด้านล่าง "จดแล้ว · ย้อนกลับ" |
| เอฟเฟกต์ +XP | ตัวเลข `+15 XP` สีม่วงเด้งขึ้นจากปุ่มแล้วจางหายไป ใช้เวลาไม่เกิน 600ms และไม่บล็อกการใช้งาน |

## สิ่งที่ค้นพบตอนทดสอบหน้าจริง
- **เลข 0 ของ Mitr มีขีดเฉียง:** พอใช้ Mitr กับยอดเงิน เลข `0` อ่านเป็น "Ø" เหมือนสัญลักษณ์อื่นมากกว่าตัวเลข ไม่เหมาะกับยอดเงิน จึงใช้ Mitr เฉพาะหัวข้อภาษาไทย และใช้ Anuphan ตัวหนา (bold) กับ **ตัวเลขทุกที่**
- **แป้นตัวเลขกระโดดตอนขึ้นบรรทัด "หาร":** ตอนเปิด toggle ออกก่อนแฟน บรรทัดสรุป "ของเรา ฿x · แฟนติด ฿y" จะโผล่ใต้ยอดที่พิมพ์ ทำให้เลย์เอาต์ด้านล่างรวมถึงแป้นตัวเลขขยับลง ทั้งที่นิ้วกำลังกดอยู่ แก้โดย **จองความสูงของบรรทัดนั้นไว้เสมอ** (`h-5` แม้ยังไม่มีข้อความ)
- **Hydration mismatch จากการ restore cache:** ถ้าอ่าน cache ของ TanStack Query จาก localStorage ก่อน render แรก HTML จาก server (ไม่มีข้อมูล) จะไม่ตรงกับ render แรกฝั่ง client (มีข้อมูลจาก cache) แก้โดย restore cache **หลัง hydrate** ใน `useEffect` ของ `src/client/Providers.tsx`
